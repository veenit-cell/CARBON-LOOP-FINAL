# CarbonLoop Mock Marketplace

This package provides a deterministic, append-only **MOCK_DEMO_ONLY** redemption domain for the hackathon. The seeded canteen catalogue and fulfilment are fictional. Green Points are closed-loop, non-cash loyalty points; they are never payments, carbon credits, offsets, or tradable assets.

Real reward partners, fulfilment, conversion rules, inventory, expiry, and financial approvals remain `NEEDS_VERIFICATION`.
